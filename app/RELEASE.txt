Save Tool
---------
1. Double-click savetool.exe. Your browser opens the Save Tool page.
2. Paste one or more links (Threads, YouTube, Instagram, Facebook, TikTok, X...), click Download.
   Files go to  Downloads\SaveTool   (change it with "Change folder" on the page).
   Click "Add shortcut" to find Save Tool on your Desktop / Start menu next time.
3. Close the black window to quit.

yt-dlp and ffmpeg are already in this folder, so nothing extra is downloaded on first use.
Keep savetool.exe, yt-dlp.exe and ffmpeg.exe together. A YouTube link downloads a small JS
runtime (deno, ~40 MB) once.
Command line:  savetool.exe <link> [folder]

Stopped working? Click "Update" on the page (updates yt-dlp).
Threads broke? It refreshes the Threads extractor from the project page on launch; you can also
drop a newer core.mjs next to savetool.exe.
Private / login-only videos: set "Login" to your browser on the page (close Chrome/Edge first),
or put a cookies.txt (exported from your browser) next to savetool.exe.
(Windows SmartScreen may warn on first run because the exe is unsigned: More info > Run anyway.)
